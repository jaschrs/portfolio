# Kestrel

A tiny x86-64 hobby kernel written in Rust.

Systems · 2026 · `Rust` `x86-64` `QEMU`

[:fontawesome-brands-github: Source](https://github.com/jaschrs){ .md-button }

## Overview

Preemptive multitasking, a buddy allocator, a VFS layer and a userspace shell, all in about 9k lines of Rust. Boots on QEMU and real hardware.
