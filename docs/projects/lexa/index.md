# Lexa

A compiler for a small functional language.

Systems · 2025 · `OCaml` `LLVM`

[:fontawesome-brands-github: Source](https://github.com/jaschrs){ .md-button }

## Overview

Hand-written lexer and Pratt parser, Hindley–Milner type inference, and an LLVM backend. Includes a REPL and a test suite of 300+ programs.
